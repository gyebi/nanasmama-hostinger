Nana's Mama Hostinger Setup Instructions

Use this guide to retrieve the Hostinger-ready project from GitHub, build it in VS Code, and upload it to Hostinger.

1. Get The Project From GitHub

  1. Open VS Code.
  2. Open the VS Code terminal.
  3. Choose where to save the project, then run:
cd ~/Documents
git clone https://github.com/gyebi/nanasmama-hostinger.git
cd nanasmama-hostinger

2. Install And Build

  1. Install dependencies:
npm install
  1. Build the production website:
npm run build

The upload-ready website will be inside:

nanasmama-hostinger/dist

3. Upload To Hostinger

  1. Log into Hostinger hPanel.
  2. Open the correct website or domain.
  3. Go to Files then File Manager.
  4. Open the domain's public_html folder.
  5. Delete Hostinger's default placeholder files, especially any old index.html.
  6. Upload everything inside the local dist folder into public_html.
Important: upload the contents of dist, not the dist folder itself.

After upload, public_html should contain:

index.html
products.html
contact.html
assets/
sitemap.xml
robots.txt

4. Domain And SSL

  1. In Hostinger, confirm the domain points to the hosting account.
  2. Enable SSL so the site loads with https://.
  3. Test these URLs:
https://nanasmama.com/
https://nanasmama.com/products.html
https://nanasmama.com/contact.html
https://nanasmama.com/sitemap.xml

5. Contact Form Email Note

The contact form uses Firebase to send email. Hostinger serves the static website, but Firebase handles the email request.

After upload, test the form here:

https://nanasmama.com/contact.html
  1. Submit a small test message through the contact form.
  2. Confirm the email arrives at nanasmamashea@gmail.com.
  3. If the form does not send, check that the Firebase Function is deployed and the RESEND_API_KEY secret is configured.
